# 3D Tracker Simple - One-Click Panel

## Quick Installation

### Method 1: Run Script (Fastest)

1. Open After Effects
2. File → Scripts → Run Script File...
3. Select `3d_tracker_simple.jsx`
4. Panel opens immediately

### Method 2: Permanent Panel

**Windows:**
```
C:\Users\[YourUsername]\AppData\Roaming\Adobe\After Effects\[VERSION]\Scripts\ScriptUI Panels\
```

**macOS:**
```
~/Library/Application Support/Adobe/After Effects/[VERSION]/Scripts/ScriptUI Panels/
```

Then restart After Effects and open from Window menu.

## How to Use

### Step 1: One-Click 3D Camera

1. Click **CREATE 3D CAMERA**
2. ✓ 3D camera is added with auto keyframes
3. ✓ Checkpoint marker is created automatically

### Step 2: Add Elements

**Solid Layer:**
- Choose color with "Pick" button
- Click "Solid"
- Layer added to composition

**Null Object:**
- Click "Null Object"
- Use to control camera or other elements

**Light:**
- Click "Light"
- Point light added to scene

### Step 3: Add More Checkpoints

- Move timeline to desired frame
- Click **ADD CHECKPOINT**
- Checkpoint layer created at current time

You can add keyboard shortcut by editing AE's keyboard shortcuts:

- Search for script name
- Assign shortcut

## Tips

- Use Null Objects as camera controllers
- Add multiple checkpoints to mark key moments
- Use Solids as backgrounds or textures
- Lights work best in 3D compositions

## Troubleshooting

**Panel not opening:**
- Use Method 1 (Run Script) instead
- Check script file is not corrupted

**Camera not added:**
- Ensure you have an active composition
- Try creating new composition first

**Effects not showing:**
- Some older AE versions may not support all features
- Try updating After Effects
